# TextFightGame 文字格斗游戏
> Java面向对象实战项目，黑马Java课程文字版回合制格斗小游戏，适合作为简历小项目。

## ✨ 项目介绍
纯控制台文字回合制RPG格斗游戏，基于Java面向对象思想开发（继承、类、集合、方法封装）。
玩家可以自定义角色属性，不断挑战随机敌人，敌人属性随战斗场次永久变强，每胜利3场角色获得属性强化。
包含多种敌人技能：普通攻击、快速攻击、猛击、火球术、防御姿态（减伤Buff）。

## 🎮 游戏玩法
1. 创建角色，分配一共50点属性点：生命值 / 攻击力 / 防御力
2. 进入回合制战斗，每回合选择技能：普通攻击 / 强力一击 / 生命汲取
3. 敌人随机出场：初级战士、敏捷刺客、重装坦克、法师，敌人拥有专属技能
4. 战斗胜利后自动回血；**累计胜利3场，玩家角色获得永久属性提升**
5. 敌人模板属性会随着战斗场次不断变强，难度递增
6. 角色阵亡或者选择退出，触发游戏结算，展示总胜场

## 📚 使用技术
- Java SE 基础语法、面向对象（继承、方法重载）
- ArrayList 集合存储敌人模板
- Random 随机数、Scanner控制台输入
- StringBuilder 字符串拼接
- 封装角色实体类：HeroCharacter、EnemyCharacter

## 🚀 如何运行
1. JDK版本：JDK21（推荐）
2. IDE：IDEA
3. 直接运行 `App` 类中的main方法，控制台开始游戏
4. 根据控制台提示输入数字选择操作
